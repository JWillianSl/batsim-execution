# Origem dos dados de exemplo

Os arquivos em `platforms/` e `workloads/` foram vendorizados a partir do
repositório oficial do Batsim (https://github.com/oar-team/batsim),
tag `v4.2.0`, para garantir compatibilidade com a imagem Docker
`oarteam/batsim:4.2.0` usada por este projeto (a imagem não inclui
nenhum arquivo de exemplo).

Batsim é licenciado sob LGPL-3.0
(https://github.com/oar-team/batsim/blob/master/COPYING).

  https://github.com/oar-team/batsim/blob/v4.2.0/platforms/small_platform.xml
- `workloads/test_one_computation_job.json`:
